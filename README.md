# Maze: Identity

Maze: Identity is a long-term Unity-based 3D exploration game that explores how identity is shaped through space, structure, pressure, and progression rather than dialogue.

The project was initially developed as an IB MYP Personal Project and continues as an ongoing creative and technical work.

---

## 🎮 Project Overview
- Engine: Unity 
- Genre: 3D Exploration / Narrative Experience
- Platform: PC
- Status: Ongoing long-term project

---

## 🌍 Global Context
**Identities and Relationships**

This project investigates how identity is formed, measured, and reshaped through systems, paths, and environments that impose structure and expectation.

---

## 🧠 Core Design Idea
**Identity is not about escaping the path, but understanding how it shapes who we become.**

Instead of using dialogue or exposition, meaning is communicated through:
- Spatial structure
- Environmental pressure
- Restricted and guided movement
- Symbolic scene transitions

---

## 🗺️ Scene Structure
1. School Maze  
2. Examination Hall  
3. Lost Place  
4. Center  
5. Inversion  
6. Summit  

---

## 🛠️ Technical Focus
- Unified trigger and transition system
- One-run continuous experience across scenes
- Scene-based pacing and symbolic progression
- Custom fade, control-lock, and video sequencing systems
